# Django curriculum — 2026-10-13

Owner requested a curated Django learning path covering startup, REST Framework and major tools used in their projects. Authored Tasks examples are a separate learning application, not copied project implementation or an executed backend. Django 5.2 is the deliberate example baseline. Reference commands, API integration and tests must be executed in a separate backend. No backend dependency was installed in this frontend handbook.

Official references consulted:

- https://docs.djangoproject.com/en/5.2/intro/tutorial01/
- https://www.django-rest-framework.org/tutorial/quickstart/
- https://www.django-rest-framework.org/api-guide/viewsets/
- https://www.django-rest-framework.org/api-guide/testing/
- https://docs.djangoproject.com/en/5.2/topics/http/middleware/
- https://docs.djangoproject.com/en/5.2/topics/signals/
- https://docs.djangoproject.com/en/5.2/topics/db/transactions/
- https://channels.readthedocs.io/en/stable/topics/security.html

Project examples link existing public-safe source studies. They do not claim the Tasks starter implements tenancy, production authentication, distributed scheduling or reliable event delivery.
