# Educational concepts review — 2026-10-17

These chapters teach concepts using original examples; they do not configure integrations, deploy services, assess compliance, or claim certification. The official publications below were reviewed for scope and terminology. Examples applying them to the handbook stack are teaching scenarios, not evidence of deployed controls.

MCP references use the official 2026-07-28 architecture, server concepts, authorization and security documentation. Older tutorials may describe a different protocol lifecycle; the educational chapter avoids version-specific setup instructions.
