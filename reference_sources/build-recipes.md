# Practical build helpers — 2026-10-13

Owner authorized a project-type starter checklist and copyable recipes. All backend and integration excerpts are authored reference examples for separate applications. No backend, scheduler, socket or authentication service is installed or executed here. Checklist progress is user-reported browser data, never automated verification.

Examples build on the existing Tasks starter, React connection, WebSocket, private-document and job-lifecycle chapters. Official references checked for API details:

- https://www.django-rest-framework.org/api-guide/permissions/
- https://tanstack.com/query/latest/docs/framework/react/guides/invalidations-from-mutations
- https://docs.djangoproject.com/en/5.2/howto/custom-management-commands/

Recipes specify dependencies and omitted integration responsibilities, particularly CSRF, credentials, tenant scope, cancellation, idempotency and live connection recovery.
