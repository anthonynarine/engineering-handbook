# Learning roadmap — 2026-10-14

Owner requested a section for things they want to learn and authorized the proposed Learning roadmap under Start here. The roadmap separates Next, Practicing and Learned from the handbook's source-inspection and implementation statuses.

Three initial topics are authored suggestions based on existing manual coverage: planned Lumen AWS trust boundaries, Gait identity/domain/session freshness and retry-safe jobs. They are not statements about the owner's skill level or chosen priorities. All are editable/removable. Exercises use synthetic data and do not execute or authorize cloud changes. Local storage and exports contain personal learning plans, not verified competency or application evidence.
