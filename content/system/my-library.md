## Your browser, your shortcuts

Save a guide using its bookmark button, then return here to reopen it. Recently viewed lists the latest distinct guide visits, newest first. Both lists are stored locally in this browser when storage is available; there is no account, cross-device sync or server-side reading telemetry.

## Keep control of the list

Remove individual bookmarks or clear a list when it is no longer useful. Clearing history does not clear bookmarks. Private browsing, cleared site data or blocked storage can prevent persistence. If storage is unavailable, the lists work only for the current open application session.

This library stores guide identifiers only, not clinical data, credentials or the contents of another project. Reading a guide does not mark an application check as executed.
