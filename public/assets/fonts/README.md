# Local fonts

DM Sans (variable) and Libre Caslon Display (regular) come from the Google Fonts repository, under their included SIL Open Font Licenses. Retrieved October 14, 2026.

- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/librecaslondisplay

The application serves these files locally. Font updates require reviewing the upstream files and licenses, followed by the normal release checks.
